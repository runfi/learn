CHAPTER 24

投资组合业绩评价

Portfolio Performance Evaluation

这是对你未来最有用的一章：怎么判断一份成绩单的真假——别人的基金，和你自己的交易系统。四件工具按顺序交付：先把收益率口径算对（TWR vs MWR），再做风险调整（四大指标怎么选），然后拆来源（归因），最后回答终极问题：这是本事，还是运气？需要多长的记录才能分清？

学习目标

  • 会算时间加权与资金加权收益率，理解两者分别评价谁
  • 掌握夏普、特雷诺、詹森 α、信息比率的公式与适用场景
  • 会做三项式业绩归因：配置效应 + 选择效应 + 交互项
  • 理解择时能力的统计指纹（收益对市场的凸性）
  • 会用 t ≈ SR × √T 估算“证明技能需要多少年”，警惕回测的多重检验陷阱

24.1两种收益率：基金的成绩单 vs 你的真实体验

TIME-WEIGHTED VERSUS DOLLAR-WEIGHTED RETURNS

时间加权 TWR：各期收益率的几何平均——与资金进出无关
资金加权 MWR：令全部现金流现值为零的 IRR——被你的申赎时点加权
评价管理人用 TWR（资金何时进出不由他决定）；评价你自己用 MWR（择时正是你的决策）。两者之差就是第 4、12 章说的行为缺口。

24.2风险调整指标：四把尺子怎么选

RISK-ADJUSTED PERFORMANCE MEASURES

指标公式分母担什么风险什么时候用
夏普比率（r̄ − rf）/ σ总波动评价全部身家所在的组合
特雷诺比率（r̄ − rf）/ β仅系统性风险它只是大分散组合的一块时
詹森 αr̄ −［rf + β(r̄M − rf)］按 CAPM 扣完 β 的剩余检验“有没有超额”，第 9 章的 α 本尊
信息比率 IRα / σ(e)（跟踪误差）主动偏离的波动评价相对基准的主动管理质量
M²把组合杠杆调到与市场同 σ 后的收益差总波动把夏普翻译成“百分点”，方便向人解释

24.3业绩归因：超额收益从哪来

PERFORMANCE ATTRIBUTION

配置效应 = Σ（wp,i − wb,i）×（rb,i − rb）　｜　选择效应 = Σ wb,i ×（rp,i − rb,i）　｜　交互项 = Σ Δw × Δr
算例：基准 50/50 股债，股票基准涨 10%、债券 2%（基准整体 6%）。你的组合 70/30，且股票部分选出 11%：组合收益 8.3%，超额 +2.3%。分解：配置 =（0.2）(10−6)+（−0.2）(2−6) = +1.6%；选择 = 0.5×(11−10) = +0.5%；交互 = 0.2×1 = +0.2%。

24.4择时能力：凸性是它的指纹

MARKET TIMING

成功的择时者会在上涨前调高 β、下跌前调低 β——于是组合收益对市场收益的散点不再是直线（第 9 章 SCL），而是向上弯的凸线：市场越好时组合的有效 β 越高。Treynor–Mazuy 检验据此在回归里加一个平方项：Rp = α + βRM + c·RM² + e——c 显著为正即择时证据。实证结论冷峻：公募基金的 c 平均约为零甚至为负（现金拖累 + 追涨杀跌），真正可证的择时能力凤毛麟角。注意一个伪装者：卖出期权型策略会制造负凸性却抬高表面夏普——平时稳稳赚权利金、极端行情一次性归还（第 2 章压路机、第 5 章尾部警告在业绩语言里的重现）。所以看任何平滑得不自然的净值曲线，先查它的凸性与尾部。

24.5运气还是本事：需要多长的成绩单

SKILL VERSUS LUCK

t 统计量 ≈ 年化夏普比率 × √年数　（要求 t ≥ 2 才算显著）
所需年数 T ≈（2 / SR）²
SR = 0.5（优秀的长期主动水平）→ 需 16 年；SR = 1（顶尖）→ 4 年；SR = 2（大奖章级）→ 1 年。三五年的亮眼业绩，在统计上几乎没有证明力。
真实案例

ARK 创新基金：一张被四件工具拆完的成绩单

2020 年 ARKK 大涨约 150%，被封“女版巴菲特”，资金蜂拥而入；2021–22 年从高点回撤约 80%。用本章工具复盘：① 口径——因为绝大多数资金在高位进场，晨星估算其投资者的资金加权收益显著为负，而成立以来的 TWR 一度仍为正（图 24-1 的真人版）；② 风险调整——150% 伴随极端波动与集中度，夏普并不出众；③ 归因——超额大部分可由“高 β + 超长久期成长风格 + 零利率环境”解释，风格 β 冒充了 α（第 9 章利率案例的反面）；④ 显著性——单一年份的爆发在 t ≈ SR×√T 面前毫无分量。四步走完，“天才叙事”还原成一次杠杆化的风格暴露。

这套四步流程（口径 → 风险调整 → 归因 → 显著性）就是你审查一切业绩的标准作业——包括将来你自己的。

常见误区

“我的回测夏普 2.0，上线稳了。”——回测的夏普要先过三道折减：① 多重检验：试过 100 个参数组合后挑出的最好者，期望值本身就被选择偏差抬高（第 11 章数据窥探的私人版，学界用“收缩 / deflated Sharpe”校正，粗暴起见先打对折）；② 成本与容量：扣足价差冲击（第 3 章）；③ 样本外：只有未参与任何调参的区间才算数。上线纪律：小资金实盘 ≥ 若干月作为最终样本外，实盘 MWR 对回测 TWR 的偏离本身就是一个监控指标。

※本章小结

SUMMARY

  1. 先对口径：评管理人用时间加权 TWR，评自己用资金加权 MWR；两者之差 = 行为缺口（追涨把 0% 做成 −32% 的算术）。
  2. 四把尺子按角色选：全部身家 → 夏普（/M²）；大组合的一块 → 特雷诺 / 詹森 α；相对基准的主动腿 → 信息比率。
  3. 归因三项式：配置 + 选择 + 交互——找出赢在哪一层决策，迭代就优化那一层。
  4. 择时的指纹是凸性：T–M 平方项显著为正才算数；负凸 + 高夏普组合要警惕卖期权型策略的尾部。
  5. 显著性门槛：t ≈ SR×√T；SR 0.5 需 16 年——短期排名无证明力；回测夏普先过多重检验、成本、样本外三道折减。
  6. 标准作业：口径 → 风险调整 → 归因 → 显著性，四步审查一切成绩单，包括自己的。

自测（先想后翻）

Q1 投入 1 万，第一年 +50%（1.5 万）后追加 1.5 万（共 3 万），第二年 −20% 剩 2.4 万：TWR 与 MWR 各是多少？

TWR =（1.5 × 0.8）1/2 − 1 ≈ +9.5%/年——基金层面两年是赚的。MWR 解 −1 − 1.5/(1+r) + 2.4/(1+r)² = 0，得 r ≈ −2.9%/年——你实际投入 2.5 万只拿回 2.4 万。同一段历史，经理及格、你不及格，差的是追加的时点。给自己记账，请永远算 MWR。

Q2 三个场景各用什么指标：① 全部积蓄放在一个全球配置组合；② 组合里 5% 仓位的半导体行业基金；③ 一只沪深 300 指数增强基金？

① 夏普比率（你独自承担全部波动，总 σ 才是真实风险），辅以最大回撤；② 特雷诺 / 詹森 α——它的特有波动会被你另外 95% 的持仓分散掉，只有 β 部分的性价比与你有关；③ 信息比率——指增的全部使命是“相对基准的主动偏离”，IR = α ÷ 跟踪误差正好度量每单位主动风险买到多少超额。用错尺子（比如拿夏普评行业基金）会系统性冤枉或高估。

Q3 组合年化 15%，β = 1.2，rf = 3%，市场 11%，跟踪误差 4%：詹森 α 与信息比率各是多少？

应得收益 = 3% + 1.2 ×（11% − 3%）= 12.6%；α = 15% − 12.6% = +2.4%。IR = 2.4% / 4% = 0.6——这是相当优秀的主动管理水平（长期 IR 能稳定在 0.5 以上已属一流）。下一问应是 24.5 的：这个 α 的 t 值够吗？t ≈ IR × √T，0.6 的 IR 需要约 11 年才过显著性门槛。

Q4 基准 40/60 股债，股票基准涨 12%、债券 3%；你的组合 60/40，股票部分赚 12%、债券部分赚 4%：做三项归因。

基准收益 = 0.4×12 + 0.6×3 = 6.6%；组合 = 0.6×12 + 0.4×4 = 8.8%；超额 +2.2%。配置 =（0.6−0.4）(12−6.6) +（0.4−0.6）(3−6.6) = 1.08 + 0.72 = +1.8%；选择 = 0.4×(12−12) + 0.6×(4−3) = +0.6%；交互 =（0.2)(0) +（−0.2)(1) = −0.2%。合计 1.8 + 0.6 − 0.2 = +2.2% ✓。解读：这次赢在敢于超配股票（配置 1.8%），债内选券贡献小头，交互为负（超配的那类没有选券优势）。

Q5 你的系统回测年化夏普 0.8。按显著性门槛需要几年实盘？上线前还要做哪三道折减？

T ≈（2/0.8）² ≈ 6.3 年——这还是假设回测夏普无偏的乐观值。三道折减：① 多重检验：若这是几十次调参挑出的最优版本，期望夏普先打对折再估 T（变成 25 年量级——这就是为什么“策略组合 + 低相关”比单策略更现实）；② 成本：按第 3 章口径扣足价差与冲击，再看夏普还剩多少；③ 严格样本外 + 小资金实盘若干月，并持续监控实盘相对回测的衰减。把这三条写进上线清单，是本章对你的交易系统最直接的交付物。
