第 07 章 / 02学习范围、关键机制与复习问题

前置：06。目标：把“资料存在”变成“本次找到正确、可访问、可引用的证据”。

小课核心问题与机制纸面推演 / 后续验证
07.1 入库与定位解析、清洗、分块、重叠、文档/块 ID、页码/行号与版本N1/N2 命中后能回到准确原文；格式改变不混淆来源
07.2 索引的种类人工目录、结构化字段索引、倒排/全文索引、向量索引；Embedding 与相似度精确 ID 查询、关键词和语义查询各用合适路径
07.3 查询到候选查询改写、时间/用户/项目/权限过滤、关键词/向量/混合召回区分没召回、被过滤、召回过多；小数据直接提供作为基线
07.4 候选到答案去重、Top-k、重排、预算、来源组织、引用支持与无答案B1 缺失依据时不补造；找到不等于用对
07.5 更新与评估增量索引、内容哈希、版本、水位、删除、重建与模型迁移正本更新但索引滞后时查明原因；记录召回/排序/引用指标

验收：同一问题展示查询、过滤、候选、重排及最终输入；解释权限要覆盖召回、回读和输出，不能只隐藏 UI。生产规模性能与三份教学笔记实验分开。

FAQ / 示范答法：

  • RAG 就是向量数据库吗？ RAG 是先取得相关证据再生成回答，向量搜索只是找资料的一种方式。精确字段查询或全文搜索也可能更合适。
  • 向量相似度很高为什么还答错？ 相似不代表资料能支持结论，也可能已经过期或不属于当前用户。我会分别检查过滤、排序和答案使用证据的环节。
  • 数据改了为什么搜到旧内容？ 正本和索引可能不是同步更新。我会查源版本和索引水位，回读正本核验，并处理缓存失效或重建。
