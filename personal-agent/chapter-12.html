第 12 章 / 02学习范围、关键机制与复习问题

前置：已掌握可观测链路、数据生命周期、恢复与权限。目标：先学判断改动是否有效，再学让 Agent 提出和迭代改进。

小课核心问题与机制纸面推演 / 后续验证
12.1 评估对象单元/契约/端到端、回答/检索/记忆/工具/任务；离线与在线差别A/B/C 成功条件转成可检查断言，不凭最终文案判断
12.2 数据与评分基准、失败集、开发集/保留集、规则/人工/模型评分；评分偏差与来源支持同一批输入冻结配置；不让候选看到保留答案
12.3 对照与诊断随机性、多次运行、样本限制、质量/成本/延迟；归因、消融与回归区分改检索和换模型的效果；报告失败和不确定性
12.4 自我改进的层次单次自我检查、经验记忆、prompt/skill/策略调整、工具或代码自修改；参数训练边界指出究竟修改哪个产物，何时生效、影响谁
12.5 RSI 闭环失败反馈 → 候选差异 → 隔离执行 → 保留集评估 → 接受/拒绝 → 新版本参与下一轮做有限轮可停止实验；展示父子版本和一次拒绝/回滚
12.6 改进的边界评估泄漏、过拟合、投机评分、改评估器/权限、错误自强化、预算与无收益停止开发集变好而保留集退化时拒绝候选；不声称保证递归变强

RSI 实验顺序：先人工给一个有限策略候选，验证评估门槛；再让 Agent 提出同类候选；最后检查“改进后的 Agent 是否实际参与下一轮改进”。必须记录修改对象、输入证据、父版本、数据版本、成本、采纳理由和停止条件。先选择小范围可回滚的检索/记忆选择策略，不要求修改模型权重。代码自修改是后续受控实验，不能改掉验收规则或绕过权限来获得更高分。

验收：能够解释一次没有采用的改动，比只展示成功案例更有说服力。Dreaming 复用这里的评估方法，但不把整理记忆自动称为 RSI。

FAQ / 示范答法：

  • 你怎样证明 Agent 变好了？ 我会固定任务和对照版本，分开看质量、成本、延迟与权限失败，在没参与调参的数据上复查；只跑一个成功例子不够。
  • RSI 和记住一次教训有什么区别？ 记住教训通常只是更新外部记忆。RSI 还要说清 Agent 怎么改自身策略或实现，以及改进后的版本怎样参与后续改进，并用结果验证。
  • 自评得分更高为什么还不能上线？ 评分器可能偏、数据可能泄漏，也可能只优化了训练场景。我会看保留任务和回归结果，失败就拒绝或回滚。
