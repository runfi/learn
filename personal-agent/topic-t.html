工具层与 Muse

专题 T / 01位置与递进顺序

这是必学专题的学习提纲，接在第 04 章之后。具体产品正文和比较结论尚需逐项核对后撰写，不能把提纲当已核实的产品能力。

专题 T / 02通用全景

工具定义、注册与目录、按需发现、调用提议、校验、授权、执行、结果回传、记录。先区分模型看见的能力说明与执行器实际拥有的能力。

专题 T / 03准确调用

分别检查工具选对、参数格式正确、业务语义正确、结果使用正确。用同一任务比较命名、描述、Schema、示例及错误反馈。

专题 T / 04hooks 与生命周期

在发现、执行前、执行后、失败时讨论扩展点。区分事件通知、拦截与改写；会话和调度 hook 的更大范围回到运行时章节。

专题 T / 05性能与组合

按需加载、缓存、结果过滤、并行、批量与程序化编排。比较模型往返、Token、延迟、成功率与维护成本；组合后仍需处理权限、幂等、部分失败和取消。

专题 T / 06Muse 映射与证据

沿一次能力发现和调用追踪，区分连接器接入、目录加载与用法正文载入。逐项标明官方、可检查实现、Notion、推断与未知，不预设所有通用能力均已实现。

专题 T / 07理解验收

能够画出一次调用的完整生命周期；对同一任务说明逐次、批量/并行、代码编排的收益与代价。此处仅设计阅读问题，不要求现在写代码。
