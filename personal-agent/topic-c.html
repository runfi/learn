上下文机制与 Muse

专题 C / 01位置与递进顺序

这是必学专题的学习提纲，接在第 05 章之后。具体产品正文和比较结论尚需逐项核对后撰写，不能把提纲当已核实的产品能力。

专题 C / 02基础与边界

全量对话、实际上下文、持久状态与长期记忆的区别。模型调用看到的是已提供内容，不是自动拥有所有文件和历史。

专题 C / 03来源与加载矩阵

指令、消息、工具定义、结果、资料、记忆各自的来源、范围、触发者、目录/摘要/正文层级、注入位置、失效与恢复时机。优先级不等于拼接顺序，资料不自动升级成指令。

专题 C / 04预算与压缩

分配预算，保护目标、约束、未决事项、授权对象与原文指针。比较截断、滑窗、摘要和回查的收益与信息损失。

专题 C / 05生命周期

从单次调用、多轮、长任务到中断恢复。记录压缩覆盖区间、输入快照、摘要版本和新消息尾部，避免旧摘要覆盖新约束。

专题 C / 06Muse 映射与证据

跟踪普通请求与一次超预算请求，区分已证实加载、后台处理与未知部分；产品差异需要直接证据，不凭通用 API 文档推定。

专题 C / 07理解验收

独立画出组装与压缩链，追踪一条被移除信息如何找回，解释正确性、延迟、费用、可恢复性之间的取舍。
